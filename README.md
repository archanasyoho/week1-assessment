# Week 1 Assessment

Week 1 Assessment – Python and Data Engineering

1. Project Overview

This project demonstrates Python programming and data analysis skills using an employee dataset. It covers Python fundamentals, Object-Oriented Programming (OOP), file handling, JSON, API requests, NumPy, Pandas, Matplotlib, and Git/GitHub.


2. Setup Instructions

Step 1: Clone the repository

git clone https://github.com/archanasyoho/week1-assessment/tree/feature/analysis

Step 2: Create a virtual environment

python -m venv venv

Step 3: Activate the virtual environment

For Windows Git Bash:

source venv/Scripts/activate

Step 4: Install the required libraries

pip install -r requirements.txt

Step 5: Launch Jupyter Notebook

jupyter notebook

Open the notebook inside the "notebooks/" folder and run the cells.

3. Key Findings

1. The employee dataset contains 8 employee records.
2. IT has the highest number of employees, with 3 employees.
3. Sales and HR have 2 employees each, while Finance has 1 employee.
4. Marketing has no employees in the provided employee dataset.
5. Four visualizations were created to analyse employee distribution and salary patterns.
